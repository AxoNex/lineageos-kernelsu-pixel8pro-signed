# 05 · 线刷包（fastboot）制作

## 产物结构

`03-make-fastboot-package.sh` 从 target-files 解包 `IMAGES/*.img`，组装为：

```
fastboot/
├── husky-22.1-YYYYMMDD-HHMMSS/
│   ├── images/
│   │   ├── boot.img
│   │   ├── init_boot.img
│   │   ├── vendor_boot.img
│   │   ├── dtbo.img
│   │   ├── vbmeta.img
│   │   ├── vbmeta_system.img
│   │   ├── vbmeta_vendor.img
│   │   ├── pvmfw.img
│   │   ├── super_empty.img
│   │   ├── system.img / system_ext.img / product.img / vendor.img
│   │   └── android-info.txt
│   ├── flash-all.sh
│   ├── flash-all.bat
│   └── SHA256SUMS
└── husky-22.1-...-factory.zip   # 一键分发 zip
```

## 刷入（Windows / Linux / macOS）

```bash
# 进入 bootloader
adb reboot bootloader

# 保留数据
./flash-all.sh        # 或 flash-all.bat

# 清除用户数据（首次刷入建议）
./flash-all.sh -w     # 或 flash-all.bat -w
```

## 刷入逻辑

1. 刷静态分区：`boot` / `init_boot` / `vendor_boot` / `dtbo` / `vbmeta*` / `pvmfw`
2. `fastboot reboot fastboot` 进入 fastbootd
3. `fastboot wipe-super super_empty.img` 重建 super 分区布局
4. 刷动态（逻辑）分区：`system` / `system_ext` / `product` / `vendor`

> Pixel 8 Pro 为虚拟 A/B 设备，`system` 等分区属 super 动态分区，必须在 fastbootd 下刷写。

## 说明

- 本工具仅打包 LineageOS 构建产物；Google 专有分区（`radio` / `bootloader` 等）不在此列，通常无需处理。
- 回锁前请先以 `-w` 完整刷入并确认系统可正常启动。
