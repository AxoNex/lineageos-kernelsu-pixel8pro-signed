# 04 · 线刷与回锁

首次从官方/其他系统迁移到本 ROM，或需要完整重刷时使用线刷包。

## 前置

- 设备 **bootloader 已解锁**（Pixel 需在开发者选项里打开「OEM unlocking」后
  `fastboot flashing unlock`，会清除数据）。
- 本机装好 [platform-tools](https://developer.android.com/tools/releases/platform-tools)（fastboot + adb）。

## 一、一键线刷（含刷入信任根）

线刷包里已内置 `flash-all.sh`（Linux/macOS）和 `flash-all.bat`（Windows），
会**自动刷入信任根公钥 + 所有分区**，两步合一。

```bash
# 1. 下载 Release 里的 <版本>-fastboot.zip 并解压
unzip <版本>-fastboot.zip -d flash/

# 2. 设备进入 bootloader
adb reboot bootloader        # 或关机后长按 电源+音量下

# 3. 一键刷入
cd flash/
sh flash-all.sh              # Windows 双击 flash-all.bat
```

脚本先校验设备为 husky，然后依次：

1. `fastboot erase avb_custom_key` + `fastboot flash avb_custom_key avb_pkmd.bin`
   —— 烧入硬件信任根（回锁前必须）。
2. `fastboot flashall --skip-reboot` —— 按 avbroot 生成的 `fastboot-info.txt`
   刷静态分区 → 重启进 fastbootd → 刷动态分区（system/system_ext/product/vendor）。

> 刷完先 `fastboot reboot` 进系统确认能正常开机，**再做回锁**（见下）。

## 二、手动烧入硬件信任根（不想要一键脚本时）

信任根公钥 `avb_pkmd.bin` 会随线刷包 / Release 一起分发。回锁前把它烧入
`avb_custom_key` 分区，让 bootloader 只信任我们自己签名的启动链：

```bash
fastboot reboot bootloader        # 确保在 bootloader
fastboot erase avb_custom_key
fastboot flash avb_custom_key avb_pkmd.bin
```

## 三、回锁 bootloader

确认系统能正常开机后：

```bash
fastboot flashing lock
```

回锁后 bootloader 以 `avb_custom_key` 里的公钥为信任根校验启动链，
只有用你的 `avb.key` 签名的镜像才能通过 AVB 校验，实现「带锁的安全启动」。

## 四、以后升级

回锁后**无需再解锁**，直接走 OTA（系统更新器从你的自定义源拉取，
见 [05-OTA与自定义更新源](05-OTA与自定义更新源.md)）。

## ⚠️ 重要提醒

1. **先烧信任根再回锁**：如果直接 `flashing lock` 而没有先烧 `avb_custom_key`，
   bootloader 会用出厂默认信任根，你自签名的镜像将无法启动。
2. **密钥 = 命根子**：`avb.key`/`ota.key` 一旦丢失，无法再签新镜像，
   只能解锁（清数据）+ 烧回官方固件 + 换新钥重来。
3. **想回到官方 ROM**：`fastboot flashing unlock`（清数据）→
   `fastboot erase avb_custom_key` → 刷官方 factory 镜像。
4. 本方案**未 root**（用 `--prepatched` 换内核而非 Magisk），回锁是安全的。
   若未来叠加 Magisk root，回锁有硬砖风险，务必保持 OEM unlocking 开启。
