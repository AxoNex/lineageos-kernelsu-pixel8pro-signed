# 01 · 概览与前置条件

## 目标

为 Pixel 8 Pro（代号 `husky`）产出自签名、可回锁 bootloader 的：
- **线刷包**（fastboot 一键刷入）
- **OTA 更新包**（Recovery / 系统更新安装）
- **自定义更新源**（系统更新指向自建服务器）
- **硬件信任根**（`avb_custom_key.bin`，支持回锁）

## 整体流程

```
① 生成签名密钥（含 AVB 信任根密钥）
        ↓
② 构建 target-files 包（可选注入 blu_spark 内核）
        ↓
③ 全量镜像自签名
        ↓
④ 线刷包打包 ─────┐
⑤ OTA 包制作 ─────┤
⑥ 自定义更新源 ────┘
⑦ 提取硬件信任根 + 回锁引导
```

一键执行：`./scripts/make_all.sh`。

## 前置条件

### 构建机（Linux）
| 项 | 要求 |
|----|------|
| 系统 | Ubuntu 20.04 / 22.04（推荐） |
| 磁盘 | ≥ 250 GB 空闲（源码 + 编译产物） |
| 内存 | ≥ 16 GB |
| 工具 | `repo`、`git`、`python3`、`zip`、`unzip`、`fastboot`（platform-tools） |

### 源码树
- 按 [LineageOS 官方构建文档](https://wiki.lineageos.org/devices/husky/build) 初始化并同步 LineageOS 源码树（Pixel 8 Pro 设备树为 `device/google/shusky`）。
- 确认 `lineage/scripts/lineage-priv-template` 目录存在（用于生成密钥）。

### 设备
- Pixel 8 Pro 已解锁 bootloader。
- 开发者选项中已开启 **OEM 解锁** 与 **USB 调试**。

## 配置

```bash
cp config.env.example config.env
```

关键字段：`ANDROID_BUILD_TOP`（源码根目录）、`OUT_DIR`（成品输出）、`UPDATER_BASE_URL`（自定义更新源，先占位）。

## 名词速查

| 名词 | 说明 |
|------|------|
| `husky` | Pixel 8 Pro 代号 |
| `shiba` | Pixel 8 代号 |
| target-files | 构建产出的中间包，含全部分区镜像与签名信息 |
| AVB | Android Verified Boot，启动时验证 |
| `avb_custom_key` | Pixel 上用于存放自定义信任根公钥的分区 |
| `WITH_AVB` | 构建变量，控制是否用自建 AVB 密钥签名 vbmeta |
