# 01 · 概览与前置条件

## 这是什么

一套在 **GitHub Actions 免费 runner** 上运行的一键脚本，把 LineageOS 官方 OTA
重打包为**自签名 + blu_spark 内核 + 自定义更新源**的 ROM，产出：

| 产物 | 说明 |
|------|------|
| `<版本>-fastboot.zip` | 线刷包，`fastboot flashall` 一键刷入 |
| `<版本>-ota.zip` | 全量 OTA 包，供系统更新器增量升级 |
| `updates.json` | 自定义更新源（托管在 GitHub Pages） |
| `avb_pkmd.bin` | 硬件信任根公钥，烧入后支持 bootloader 回锁 |

## 为什么不是「源码构建」

LineageOS 完整源码构建需要约 **250GB 磁盘 / 32GB 内存**，远超免费 runner 的
14GB 盘 / 7GB 内存 / 6 小时上限。重打包路线只需解压、改文本、重打包、签名，
磁盘与内存占用小得多，**免费版 ubuntu-latest 即可完成**。

## 核心工具

- **avbroot**（github.com/chenxiaolong/avbroot）：重打包 + 重签名 A/B OTA 的独立 Rust
  二进制，替换分区、重签 vbmeta、换 OTA 证书、重建 AVB 信任链。
- **blu_spark**（github.com/engstk/gs）：Pixel 系列自定义内核，本方案用其 `gs-los`
  预编译 boot 镜像（LineageOS 专用，无需源码编译）。
- **LineageOS v2 API**（`https://download.lineageos.org/api/v2/devices/<设备>/builds`）：
  检测上游版本 + 下载官方 OTA。

## 前置条件

| 项 | 要求 |
|----|------|
| GitHub 仓库 | **public**（免费账户 private 仓库无法启用 Pages） |
| 设备 | Pixel 8 Pro（codename `husky`），bootloader 已解锁 |
| 本机工具 | `fastboot` + `adb`（platform-tools），仅首次线刷/回锁需要 |
| 磁盘 | 每台 runner 临时用约 5~8GB（含 1.4GiB OTA + 解包中间产物） |

## 术语

- **AVB**（Android Verified Boot）：分区校验链，bootloader 依 `vbmeta` 逐级验证。
- **信任根（avb_pkmd.bin）**：自定义 AVB 公钥，烧入 `avb_custom_key` 分区后，
  bootloader 只信任用它签名的启动链，从而可安全回锁。
- **otacerts.zip**：系统内 OTA 签名证书集合；avbroot 把它替换成自定义证书，
  使系统更新器只接受我们自己签名的 OTA。
